## 📌 Project Overview
This repository project is a comprehensive guide to exploratory data analysis (EDA) visualization. It demonstrates how to convey clear statistical narratives through elegant charts, customized axes, thematic styling, and multi-panel figures.

---

## 📈 Visual Grammar & Topics Covered
1. **Matplotlib Core Architecture**:
   - Figure vs Axes object hierarchy.
   - Line plots, markers, line styles, labels, legends, grids.
   - Subplots layout (`plt.subplot` and `plt.subplots(nrows, ncols)`).
2. **Statistical Distributions**:
   - Histograms with custom binning and Kernel Density Estimation (KDE).
   - Box plots demonstrating five-number summaries (Min, Q1, Median, Q3, Max) and outliers.
3. **Categorical & Correlational Visuals**:
   - Bar plots and categorical frequency countplots.
   - Correlation heatmaps with customized color maps (`coolwarm`, `viridis`) and annotation formatting.
4. **Figure Aesthetics**:
   - Seaborn themes (`darkgrid`, `whitegrid`).
   - Sizing, aspect ratios, titles, axis rotations, and layout adjustments (`tight_layout()`).
